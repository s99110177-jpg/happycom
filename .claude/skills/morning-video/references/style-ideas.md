# 스타일 아이디어 목록

새 스타일을 고를 때 참고한다. 이미 만든 스타일은 ✅로 표시했다. 한 스타일 세트 안에서는 세 영상의 매체가 서로 달라야 한다.

## 이미 만든 스타일

| 키 | 부산 배경 | 기념일 | 캐릭터 |
|---|---|---|---|
| a ✅ | 광안대교 해돋이 / 감천문화마을 일러스트 | 그라데이션 카드 + 이모지 + 축하 종이 조각 | 해변에서 말풍선 인사 |
| b ✅ | 해운대 해변 + 잡지풍 큰 숫자 타이포 | 일력(어제 장이 뜯겨 나감) | 페이퍼컷, 현수막 끌고 비행 |
| c ✅ | 레트로 여행 포스터(용두산·부산항) | 네온사인(지직 켜짐) | 8비트 픽셀 게임 + RPG 대화창 |
| d ✅ | 수채화 태종대 등대(물감 번지며 완성) | 칠판 분필 손글씨 | 다이어리 스크랩북(폴라로이드·스티커) |
| 단독 ✅ | 실사풍 새벽 광안대교(`--only photo`) | — | 캐릭터 애니메이션(`--only anim`) |

## 다음 후보

부산 배경
- 시네마틱 와이드: 위아래 검은 띠(레터박스), 영화 타이틀 같은 자막, 필름 그레인
- 아이소메트릭 3D 미니어처: 부산역·광안리·해운대를 블록 디오라마로 표현, 틸트 시프트 흐림
- 지하철 노선도: 부산 도시철도 색 선을 따라 점이 이동하고 "오늘 역"에 날짜 표시(공식 노선도를 그대로 베끼지 말고 단순화)
- 야경에서 아침으로 넘어가는 타임랩스: 하늘색 변화와 불빛이 꺼지는 순서
- 크레파스 그림: 어린이 그림처럼 굵은 질감과 삐뚤빼뚤한 선

기념일
- 신문 1면: 헤드라인 "오늘은 ○○의 날", 날짜 머리글, 단(column) 레이아웃, 하프톤 사진 대신 일러스트
- 날씨 예보 방송 화면: 지도 대신 날짜 카드, 기념일을 '오늘의 예보'로 표현
- 우표/엽서: 기념 우표 디자인, 소인 도장이 찍힘
- 타자기: 종이에 한 글자씩 탁탁 찍히는 효과와 타자 소리
- 미니멀 타이포: 흰 배경에 큰 글자 하나와 키네틱 타이포그래피

캐릭터
- 종이접기(오리가미): 접힌 면에 음영을 넣은 각진 갈매기
- 클레이/스톱모션 느낌: 프레임을 12fps로 끊고 손자국 질감과 살짝 흔들리는 위치
- 그림자 인형극: 실루엣 갈매기와 따뜻한 조명
- 4컷 만화: 기상 → 세수 → 출근 → 인사, 컷마다 0.8초
- 손그림 플립북: 연필 선이 매 프레임 조금씩 떨림(boiling line)

## 기술 메모

- 손그림 떨림: 선 좌표에 프레임마다 다른 ±2px 노이즈를 주고 6~8fps로 갱신하면 손으로 그린 애니메이션처럼 보인다.
- 저해상도 픽셀: 270×480에 그린 뒤 `Image.NEAREST`로 4배 확대하고 `draw.fontmode = "1"`을 쓴다(`scene_character4.py` 참고).
- 실사풍: HDR 값으로 계산한 뒤 `255*(1-exp(-x*k/255))`로 톤매핑하고, 블룸·그레인·비네팅을 더한다(`scene_photo.py` 참고).
- 오디오: `melody(notes, harmonics=...)`에서 홀수 배음 `(1,1),(3,.33),(5,.2)`를 쓰면 칩튠, `(1,1),(2,.2)`는 부드러운 음색이 된다. 효과음은 numpy 노이즈 버스트로 만든다.
